Hiya this is Voidbound!

An open world sandbox, where your code (**YES YOUR CODE**) can have an effect on a shared game world.

This is supposed to be a website similar to [Soap](https://soap.hackclub.com) but for godot! It will allow users to code in GDScript, C#, or C++ to add to a shared world!

Anyways :D

You can check out the project at [voidbound.yaszu.xyz](https://voidbound.yaszu.xyz) and the source code at [Github](https://github.com/Yaszu-Mage/Voidbound)

There is also Windows and Linux Builds (though I am too lazy to put them in releases)

You can build the source code by opening the project in Godot and exporting, or building the java server with ```./gradlew shadowJar``` and find and run the server file with ```java -jar server-1.0-SNAPSHOT-all.jar```
